# MultiControls

## Introduction

This sample demonstrates a Win32 C++ application that uses multiple Win32 controls, including a progress bar, a status bar, 
and a button. Also demonstrates the use of CRTP for extensible controls and windows, RAII, creating and setting fonts, 
error handling, message reflection, and basic event handling.

## Notes

Only x64 builds are supported, as Win32/x86 is dead for all intents and purposes. C++23 or later is required.
